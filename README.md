# Weather App (CSS)

![Status](https://img.shields.io/badge/status-completed-green)

## Overview

This is a simple, stylish weather application built using HTML and CSS. It displays current weather information with a clean, responsive design. Perfect for practicing CSS layouts and visual styling.

## Features

- Displays current weather data
- Responsive and mobile-friendly design
- Uses only HTML and CSS (no JavaScript)
- Clean and modern UI

## Usage

Open the `index.html` file in your favorite browser to view the app.

## Technologies

- HTML5
- CSS3
